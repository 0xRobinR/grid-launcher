Tutorials
Live codes, one scanNEW
1. On the sharing phone, a big launcher shows one live code that plays its frames on a loop. 2. On the other phone, tap Scan a code (allow the camera once). 3. Hold it on the live code for a second or two while the ring fills. 4. Choose to add its screens or switch to it.
Share by scanning
Settings › Share your launcher, or Share this screen, shows one code. A big launcher becomes a live code. Save image or Share image sends it as one picture.
Import a shared code
Settings › Import a shared code › Scan a code, and hold the camera on the other phone. Got a picture instead? Use From a screenshot.
